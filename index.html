Open source Kubernetes operator for Kanidm

Manage Kanidm on Kubernetes with confidence.

Deploy, configure, and operate Kanidm clusters and identity resources through the Kubernetes API. Built for declarative workflows, predictable reconciliation, and GitOps.

Open source · Kubernetes-native · Built in Rust

apiVersion: kaniop.rs/v1beta1

metadata:
  name: my-idm
spec:
  domain: idm.example.com
  replicaGroups:
    - name: default
      replicas: 3

ARCHITECTURE

Kubernetes-native by design.

Kaniop continuously reconciles Kubernetes custom resources. Kubernetes defines the desired deployment state, Kaniop coordinates operations, and Kanidm remains responsible for identity, persistence, and replication correctness.
